The last words of a phone at 1 percent: it survived a fall off a second-floor balcony, only to die because someone watched one more reel.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
